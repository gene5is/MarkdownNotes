## 第一部分 《测绘学概论（第三版）》宁津生

> 大纲三点要求：测绘基础概念；测绘遥感 GIS 社会价值；测绘遥感在低空经济典型场景应用。 备考提示：重概念、简答、案例；复杂平差计算不做重点。

### 模块 1 测绘学基础概念（名词解释、简答必背）

1. 测绘学定义、研究对象、学科分支
   - 大地测量学、摄影测量与遥感、地图制图、GIS、工程测量、GNSS 导航定位
2. 3S 技术：GPS/GNSS、RS 遥感、GIS 地理信息系统，各自内涵与相互关系
3. 时空基准、坐标系统、高程基准；北斗 / GNSS 定位基础概念；RTK、PPK 基本原理（不用复杂公式）
4. 实景三维、数字孪生、CIM 城市信息模型概念
5. 测绘地理信息在国民经济、国防、社会发展中的地位与作用

### 模块 2 遥感、GIS 核心基础

1. 遥感基本原理，传感器分类；无人机航测（倾斜摄影、激光雷达 LiDAR）概念
2. GIS：数据模型、空间分析功能；时空数据特点
3. 测绘数据生产全流程：采集‑处理‑解译‑成果输出

### 模块 3【重中之重】测绘遥感在低空经济场景应用（论述高频）

> 考试极爱考：技术 + 低空场景结合，背诵时每个点要能写案例。

1. 高精度定位导航对低空飞行器的意义：安全飞行、电子围栏、航路规划、起降点定位
2. 遥感 / GIS 支撑低空空域数字化：空域网格化、适飞区 / 禁飞区建模、航路网规划
3. 无人机航测典型低空应用场景：
   - 自然资源调查、应急测绘、电力巡检、农林植保、城市治理
   - 低空物流、低空旅游、eVTOL 运行保障
4. UTM 无人机交通管理平台，测绘时空数据底座起到什么作用中国测绘学...
5. 测绘技术支撑低空经济现存挑战：数据现势性、三维模型精度、数据安全、海量数据处理压力

> 简答模板记忆：**技术原理 + 低空场景干什么 + 带来什么价值 + 现存局限**

## 第二部分 《信号与系统引论》郑君里

> 大纲三点：信号、系统基础概念定理；低空场景信号描述、分解、变换、传输处理；低空系统建模、特征分析。 备考提示：不钻超难计算；重点掌握物理含义，能够联系无人机机载信号、通信、传感器信号。

### 模块 1 信号基础

1. 信号的分类：连续 / 离散；确定 / 随机；周期 / 非周期；一维与多维信号
2. 典型信号：阶跃、冲激信号，抽样信号 Sa (t) 基本性质
3. 信号基本运算：移位、尺度变换、反转、分解
4. 频谱、带宽的概念；信号失真的条件

### 模块 2 系统基础

1. 系统定义；线性、时不变、因果、稳定系统四大特性（名词解释 + 简答）
2. LTI 线性时不变系统；时域分析：冲激响应、卷积的物理意义
3. 变换域基础概念：傅里叶变换、拉普拉斯变换、Z 变换**物理含义**（不用死磕复杂计算）
4. 抽样定理的概念与工程意义（低空传感器采样高频考点）

### 模块 3【重点】面向低空技术的信号与系统应用（综合大题）

1. 无人机机载传感器信号：感知信号采集、抽样、噪声、信号处理
2. 低空通信场景：飞行器无线信号传输、多径干扰、带宽需求；信号滤波
3. 把无人机飞控整体看成一个系统：系统建模、系统稳定性、因果性分析
4. 低空场景信号面临的现实问题：电磁干扰、复杂环境噪声、信号传输时延，如何通过信号系统方法缓解。

> 背诵思路：记住概念，能够举例：“在无人机 XX 场景中，XX 信号 / 系统理论起到 XX 作用”。

## 第三部分 《西方经济学（第二版）马工程》上下册

> 大纲三点：经济学原理分析框架；微观宏观逻辑、模型图形解读；经济学视角分析低空新兴产业、政策机制。 备考提示：不仅背理论，要训练用经济学工具解释低空经济现象。

### 模块 A 微观经济学（上册）

1. 导论：稀缺性、实证分析 vs 规范分析；微观与宏观经济学区别
2. 需求、供给与均衡价格
   - 需求供给影响因素、均衡价格；弹性概念（需求价格弹性）
   - **迁移：低空飞行器、无人机零部件市场供需变化分析**
3. 消费者行为理论：效用、无差异曲线、消费者均衡
4. 生产与成本理论：生产函数、边际报酬递减；显成本、隐成本、机会成本；规模报酬
5. 市场结构：完全竞争、垄断、垄断竞争、寡头市场特点
6. **市场失灵（超级高频）**
   - 垄断、外部性、公共物品、信息不对称
   - ✅低空迁移：低空空域属于公共资源；低空产业外部性（安全风险、噪声污染）；监管如何弥补市场失灵。

### 模块 B 宏观经济学（下册）

1. GDP 核算基本概念；总需求‑总供给 AD‑AS 模型基本含义
2. IS‑LM 模型核心逻辑（理解为主，不深挖复杂推导）
3. 经济增长、新质生产力；产业政策；财政政策、货币政策基础逻辑
4. 经济波动，创新驱动产业发展逻辑

### 模块 C【最高频】经济学视角分析低空经济（论述必背素材）

> 综合大题必考，务必整理，把理论和产业绑定。

1. 低空经济产业属性：新兴战略性产业，新质生产力载体；产业链划分（上游制造、中游运营平台、下游应用场景）
2. 低空空域经济学属性：公共资源，资源稀缺；空域改革的制度经济学分析
3. 低空产业成本收益分析：飞行器成本、基建成本（起降点、无人机云平台）、商业化落地收益；为什么很多场景难以盈利
4. 低空经济市场失灵表现：
   - 负外部性：噪声、安全风险；
   - 公共物品：空域资源、飞行服务平台；
   - 信息不对称：飞行器适航、运营风险。
5. 政府政策作用：空域制度改革、产业扶持、监管政策；政府与市场边界。
6. 低空经济面临的经济学挑战：规模效应不足、产业链不成熟、监管制度滞后，给出对策。

> 答题范式：**经济学理论概念 + 低空产业现象 + 问题分析 + 对策建议**

## 第四部分：考试通用综合专题（必背，跨三科交叉，用于第二部分选做大题）

> 大纲明确要求：评估**技术可行性、经济价值、社会影响**，批判性思考，提出创新解决方案。

### 专题 1：典型低空案例素材库（考试拿来就用）

1. 低空物流无人机；2. 电力巡检无人机；3. 低空旅游；4.eVTOL 城市空中交通；5. 无人机应急救援。 每个案例要准备三段： ①技术层面：测绘 / 信号技术如何支撑； ②经济层面：成本、收益、市场痛点； ③社会影响：好处（效率提升）、风险（安全、噪声）。

### 专题 2：低空经济共性挑战（通用答案素材）

1. 技术挑战：高精度定位、复杂环境信号抗干扰、海量时空数据处理；
2. 经济挑战：成本高、商业模式不成熟、盈利难；
3. 制度监管挑战：空域管理、适航标准、安全监管体系；
4. 社会层面：公众安全顾虑、噪声扰民。

### 专题 3：对策思路（可直接写在论述结尾）

技术迭代降本；完善空域制度改革；构建低空数字底座（测绘 GIS）；完善通信信号保障；政府引导 + 市场主导；试点先行逐步推广。
